# FastStudio

*A modern, beautiful admin studio for FastAPI.*

> **This project is under active development.** Version 0.0.1 is a
> placeholder that reserves the name; it contains no functionality.
> The first usable release will be **0.1.0**.

FastStudio will add a polished, Django-Admin-style admin panel to any FastAPI
application backed by SQLAlchemy 2.0 (async), with a modern React UI shipped
inside the wheel.

Follow progress at https://github.com/bekzod818/faststudio.
